# session-retrospective

セッションで起きた手戻りから、エージェントが働く**環境**（検査・権限・指示・docs）を直す提案を作る。対象のコードは直さない。提案し、承認されたものだけを書き出す。

## 手順

### 1. 一次資料を集める

- 引数なし: 今のセッションを振り返る。会話そのものが一次資料なので、transcript は取り込まない。手順 2 へ進む。
- transcript のパス: 作業ディレクトリの中にあって読めるなら、コピーせずにそのまま下の `digest.sh` に渡す。読めなければ `recent <N>` と同じくコピーしてもらう。
- `recent <N>`: 直近 N 件の過去のセッションを振り返る。transcript は `~/.claude/projects/<project>/<session>.jsonl` にあり、作業ディレクトリの外で読めないことが多い。置き場にコピーしてもらう。

置き場は、セッションの環境の案内（system prompt の Environment）に scratchpad があれば `<scratchpad>/session-retrospective/`、無ければ作業木のルートの `.scratch/session-retrospective/` にする。`.scratch/` が ignore されていなければ `git rev-parse --git-path info/exclude` が示すファイルに足す。scratchpad のパスは環境の案内から取り、環境変数から組み立てない。

ユーザーに、`!` を付けて次を実行するよう頼む（`<dir>` は置き場の絶対パス、`<N>` は件数に置き換えて示す）。

```bash
! mkdir -p <dir> && ls -t ~/.claude/projects/*/*.jsonl | head -<N> | xargs -I{} cp {} <dir>/
```

コピーできたら要約を作り、`digest.md` を読む。

```bash
${CLAUDE_SKILL_DIR}/scripts/digest.sh <dir>/*.jsonl > <dir>/digest.md
```

`digest.md` には、セッションの一覧・Stops（hook・auto mode classifier・permission rule に止められた呼び出しと、ユーザーが拒否・中断した呼び出し）・Tool errors（メッセージごとの回数と例）・ユーザーのプロンプトが入る。`digest.sh` が「レコードが見つからない」で止まったら、transcript の形式が変わっている。そのことを報告して止める（スクリプトを直すのが正しい対処で、その場の jq で補うと次回また同じ組み直しになる）。

完了条件: 対象のセッションごとに、ユーザーのプロンプトと Stops・Tool errors を読める状態になっている。

### 2. 教訓を拾う

次を手がかりに、手戻りを探す。観点ごとの見つけ方は [references/lenses.md](references/lenses.md) にある。

- Stops と Tool errors の、回数の多い項目
- プロンプトで、ユーザーが訂正・差し戻し・問い返しをした箇所（「違う」「戻して」「なんで」「〜では？」）
- 同じ依頼や同じ説明を、ユーザーが繰り返している箇所
- ユーザーに `!` での実行や `/add-dir` を頼んだ箇所

前後の文脈が要るときは、該当する transcript を `rg` で引いて確かめる。

教訓ごとに次の 4 つを書く。

- 最初の失敗: 何をして、どう失敗したか
- 最終的な解決: 何で解決したか
- 先に知っていれば済んだこと: 次のセッションへの指示として、命令形の 1 文で書く
- 根拠: どのセッションで、何回起きたか

完了条件: Stops と Tool errors のうち 2 回以上起きた項目のすべてに、教訓にしたか、拾わなかった理由（一度きり・外部の障害・意図した確認）がある。

### 3. 行き先を決める

機械で止められるものほど上を選ぶ。上の行き先で守れるなら、下には書かない。

| 行き先 | 選ぶとき |
|---|---|
| lint・formatter・型・CI | コードや設定の形で検出できる |
| hook | ツール呼び出しの形で検出でき、lint では届かない |
| settings.json（permissions・sandbox） | 権限・読取・書込・ネットワークの不足や過剰で止まった |
| CLAUDE.md / AGENTS.md | 毎回守る短い指示で、判断を伴わない |
| docs（CLAUDE.md・AGENTS.md から参照する） | 特定の対象を触るときだけ要る方針 |
| skill（新規・既存への追記） | 手順や判断を伴い、複数のリポジトリで繰り返す |
| memory | ユーザーやプロジェクトについての事実で、リポジトリに書く場所が無い |
| 不採用 | 一度きり。commit message や PR に残せば足りる |

置き場所について CLAUDE.md に方針があれば、この表より優先する。

完了条件: すべての教訓に、行き先と、それを選んだ理由が 1 行ずつある。

### 4. 既存と突き合わせる

教訓ごとに検索の鍵を 2〜3 個（ツール名・エラー文・症状を表す語）決め、次を探す。

- 会話に読み込まれている CLAUDE.md・AGENTS.md
- 作業ディレクトリの `docs/`・`.claude/settings.json`・hook・lint の設定
- `~/.claude/skills/*/SKILL.md`（`rg <鍵> ~/.claude/skills`）

結果を次の 4 つに分ける。

- 新規: 該当が無い
- 既存に追記: 関連する記述があり、新しい部分を足す
- 既存で足りるはずなのに起きた: 記述はあるのに守られていない。同じ文を足さず、機械で止める方法か、記述の言い回しや置き場所（常に読み込まれるか）を見直す提案にする
- 判断できない: 読めない場所（作業ディレクトリの外の settings.json など）にある。確かめなかった場所を書き、ユーザーに判断を求める

あわせて、規則（CLAUDE.md・docs）と、それを強制する仕組み（hook・settings.json・CI）の効く範囲が揃っているかを見る。たとえば hook はユーザースコープで全リポジトリに効くのに、規則が 1 つのプロジェクトの CLAUDE.md にしか無ければ、他のリポジトリでは規則を知らないまま hook に止められる。

完了条件: すべての教訓に、4 つのどれかと、その根拠（ファイルと節、または探した場所）がある。規則と強制する仕組みの両方が関わる教訓には、両者の効く範囲を確かめた結果がある。

### 5. 提案する

採用されたらそのまま適用できる粒度で書く。

- 変更の中身は、差分・設定・文案そのものを示す。「hook を足す」のような方針だけで止めない
- hook・settings.json など版で変わる仕様に依存する提案は、公式 docs で確かめてから書き、確かめた版を添える
- 指示の文案は、禁止する形だけでなく代わりにどうするかを書く。禁止だけだと、エージェントは別の形で試し続ける
- 効いたかをその場で観測できない変更（hook・権限・別のリポジトリ）には、適用後に手で確かめる手順を番号付きで添える

次の形で示し、どれを採用するかを聞く。教訓が無ければ、提案 0 件で終えてよい。

```markdown
## 振り返り

### 教訓 1: <短い見出し>
- 最初の失敗: <1 行>
- 最終的な解決: <1 行>
- 先に知っていれば済んだこと: <命令形の 1 文>
- 根拠: <セッション・回数>

## 提案

採用の候補:
1. [<行き先>] <何をどこに足す・直すか>（教訓 1。<新規 / 既存に追記 / 既存で足りるはずなのに起きた>: <根拠>）
   - 変更の中身: <差分・設定・文案>
   - 確かめ方: <適用後に手で確かめる手順。その場で観測できる変更なら省く>

既存で足りる（提案なし）:
- 教訓 N: <ファイルと節> で足りている

不採用:
- 教訓 N: <理由>
```

空になった節は見出しごと省く。

### 6. 書き出す

採用されたものだけを書く。

- 作業ディレクトリの中: その場で書き、関係する検査（lint・formatter・テスト）を回す
- 作業ディレクトリの外（グローバルの CLAUDE.md・別のリポジトリの settings.json など）: 編集しない。そのリポジトリで Claude Code に渡すプロンプトを、教訓・行き先・根拠ごと 1 つのコードブロックで出す。`handoff` skill が使えるなら、行き先を別のリポジトリのセッションとして handoff に書かせる。使えなければ自分で書く

### 7. 片付ける

transcript のコピーと `digest.md` を消す。transcript には読んだファイルの中身やコマンドの出力がそのまま入っていて、秘密情報が混ざり得る。同じ理由で、transcript の中身を外部のサービスに送らない。
